# 나만의 퀴즈 게임

## 1. 프로젝트 개요
Python 기본 문법과 객체 지향 프로그래밍(OOP) 설계를 활용하여 만든 CLI(콘솔) 기반의 퀴즈 게임 프로그램입니다.  
프로그램을 종료하고 다시 실행해도 사용자가 추가한 퀴즈와 최고 점수가 그대로 유지되도록 state.json을 통해 데이터 영속성(Persistence)을 보장하며, 견고한 예외 처리로 어떤 비정상적인 입력에도 프로그램이 크래시되지 않도록 설계했습니다.

---

## 2. 퀴즈 주제와 선정 이유
- 선정 주제: Python 기본 문법 및 Git/CS 핵심 기초 상식 (기본 5문항 구성)
- 선정 이유: 프로그래밍을 배우면서 익혀야 하는 중요한 기본 문법과 명령어들을 단순히 눈으로만 읽지 않고, 직접 문제를 풀고 새 퀴즈를 등록해보는 과정을 통해 자연스럽게 복습하고 체득하기 위해 선정했습니다.

---

## 3. 실행 방법
### ① 개발 환경 및 요구 사항
- Python 3.10 이상 
- 표준 내장 모듈(json, os, sys)만 사용하므로 별도의 외부 라이브러리 설치가 필요하지 않습니다.

### ② 실행 명령어
터미널(또는 명령 프롬프트)에서 아래 명령어를 입력합니다.

python main.py
(macOS/Linux 환경의 경우: python3 main.py)

---

## 4. 기능 목록
- 📝 1. 퀴즈 풀기: 등록된 전체 문제를 순서대로 풀며, 문항마다 정답/오답을 즉시 확인하고 최종 점수(100점 만점)와 최고 점수 갱신 여부를 안내합니다.
- 📌 2. 퀴즈 추가: 문제, 선택지 4개, 정답 번호(1~4)를 입력받아 새로운 퀴즈를 동적으로 등록하고 파일에 즉시 저장합니다.
- 📋 3. 퀴즈 목록: 현재 등록된 모든 퀴즈의 문구와 목록을 보기 쉽게 번호와 함께 출력합니다.
- 🏆 4. 점수 확인: 현재까지 기록된 역대 최고 점수(best score)를 출력합니다.
- 🛡️ 5. 예외 및 안전 처리:
  - 숫자 입력란에 공백, 빈칸(Enter), 문자열(abc), 범위 밖 숫자(9 등) 입력 시 에러 없이 재입력을 요구합니다.
  - 프로그램 실행 중 Ctrl + C 또는 EOFError 발생 시 데이터를 안전하게 저장한 뒤 종료합니다.
  - 데이터 파일 손상 시 기본 퀴즈 데이터로 자동 초기화하여 구동을 보장합니다.

## 5. 파일 구조
```
my_quiz_game/
├── .gitignore          # Git 버전 관리에서 제외할 목록
├── README.md           # 프로젝트 소개 및 설명 문서
├── main.py             # 게임 실행 로직 및 클래스(Quiz, QuizGame) 정의
├── state.json          # 퀴즈 목록 및 최고 점수가 보존되는 JSON 파일 (자동 생성)
└── docs/
    └── screenshots/    # 과제 제출 및 문서 첨부용 스크린샷 저장 폴더
 ```
---

## 6. 데이터 파일 설명 (state.json)
- 저장 위치: 프로젝트 루트 디렉터리 (/state.json)
- 인코딩 설정: UTF-8 (한글 텍스트 깨짐 방지)
- 동작 방식: 
  - 프로그램 실행 시 해당 파일이 없거나 손상되어 읽을 수 없는 경우 기본 5개 문제로 자동 생성(복구)됩니다.
  - 퀴즈를 추가하거나 최고 점수가 갱신될 때마다 최신 상태를 파일에 기록합니다.
- 데이터 스키마 구조 (JSON Structure):
  ```
  {
      "quizzes": [
          {
              "question": "Python의 창시자는?",
              "choices": [
                  "구이도 반 로섬",
                  "제임스 고슬링",
                  "리너스 토발즈",
                  "데니스 리치"
              ],
              "answer": 1
          }
      ],
      "best_score": 80
  }
```
